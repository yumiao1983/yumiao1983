# TravelNDC AI Landing Page

面向民航与旅游科技公司的响应式 AI 产品落地页，使用原生 HTML、CSS 与 JavaScript 构建。

## 内容

- 旅行科技风格 Hero、产品功能、旅程场景、信任、安全、评价、对比、定价、FAQ 与团队故事区块
- 响应式导航、平滑锚点滚动、功能手风琴、滚动进入动画与航司 Logo 横向展示
- TravelNDC 品牌配色、反白标志和机场航站楼 Hero 背景
- 33 个独立航空公司 Logo 素材，使用等比例展示框进行排版

## 本地查看

直接在浏览器打开 [public/index.html](public/index.html)，或从项目目录启动任意静态文件服务器后访问 `public/`。

## 项目结构

```text
public/
├── index.html              # 页面结构
└── assets/
    ├── styles.css           # 基础页面样式
    ├── brand-overrides.css  # TravelNDC 品牌覆盖样式
    ├── main.js              # 页面交互
    ├── hero-terminal.png    # Hero 背景图
    ├── travelndc-logo-reference.png
    └── airlines/            # 33 个独立航司标志素材
```

## 技术栈

HTML5、CSS3（Grid / Flexbox）与 Vanilla JavaScript；不依赖前端框架。
